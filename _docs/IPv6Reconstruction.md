# IPv6 Reconstruction

#### Hint 1
Understand the structure: An IPv6 address contains eight hextexts when fully expanded.

#### Hint 2
Count the groups: Count the hex texts that are already visible in the shortened address.

#### Hint 3
Calculate the missing groups: Subtract the number of existing hexes from eight to determine how many zero hexes are represented by ::.

#### Hint 4
Check the format: Every hextet in the fully expanded address must contain four hexadecimal digits.
