# Network Trace Hunt

#### Hint 1
You don’t need to read every line manually. Linux has a command that searches text for a specific pattern.

#### Hint 2
The command you’re looking for is grep. It can search a file and display only the lines that match your search term.

#### Hint 3
Flags in this challenge follow the format CTF{...}. Try searching for the distinctive text CTF{ in trace.txt.
